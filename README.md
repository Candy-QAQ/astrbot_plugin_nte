# AstrBot Plugin - 异环签到

异环自动签到插件，支持塔吉多手机号密码登录、塔吉多手机号验证码登录、云异环手机号验证码登录、多账号绑定、定时签到与云异环时长领取。

## 功能

- **nte** (私聊): 执行当前已绑定的全部账号签到，并返回签到结果与奖励明细
- **nte <序号>** (私聊): 只签到指定序号的账号
- **ntepw** (私聊): 输入手机号后，下一条消息输入密码完成登录
- **nteph** (私聊): 输入手机号后获取验证码，下一条消息输入验证码完成登录
- **nteyun** (私聊): 输入手机号后获取云异环验证码，下一条消息输入验证码完成登录并绑定云时长账号
- **ntelist** (私聊): 查看当前已绑定账号列表和序号
- **ntelogout** (私聊): 退出登录并移除全部绑定
- **ntelogout <序号>** (私聊): 删除指定序号的绑定账号
- **ntehelp** (全部): 查看命令帮助

## 使用

### 塔吉多密码登录

1. 私聊发送 `/ntepw 手机号`
2. 按提示直接发送密码完成登录
3. 可重复为同一聊天用户绑定多个账号
4. 发送 `/ntelist` 查看当前绑定列表
5. 发送 `/nte` 执行全部账号签到，或发送 `/nte 2` 只签到第 2 个账号

### 塔吉多验证码登录

1. 私聊发送 `/nteph 手机号`
2. 按提示直接发送验证码完成登录
3. 可重复为同一聊天用户绑定多个账号
4. 发送 `/ntelist` 查看当前绑定列表
5. 发送 `/nte` 执行全部账号签到，或发送 `/nte 2` 只签到第 2 个账号

### 云异环验证码登录

1. 私聊发送 `/nteyun 手机号`
2. 按提示直接发送云异环验证码完成登录
3. 可重复为同一聊天用户绑定多个云异环账号
4. 发送 `/ntelist` 查看当前绑定列表，列表会显示账号类型、手机号尾号、`uid` 或 `cloudUid`
5. 发送 `/nte` 领取全部已绑定云异环账号的每日时长，或发送 `/nte 2` 只处理第 2 个账号

### 多账号管理

- 同一聊天用户支持绑定多个异环账号
- 再次绑定相同 `uid + gameId` 的账号时会自动更新已有绑定
- 再次绑定相同 `cloudUid` 的云异环账号时会自动更新已有绑定
- 塔吉多账号和云异环账号使用相同手机号时，会自动合并为同一个账号条目
- 使用 `/ntelist` 查看当前绑定账号及其序号，列表只展示账号类型、用户标识、手机号尾号和上次签到时间
- 使用 `/nte 2` 只签到第 2 个账号；不带序号的 `/nte` 会签到全部账号
- 使用 `/ntelogout 2` 删除指定序号的账号
- 使用 `/ntelogout` 清空当前用户的全部绑定
- 签到结果会按账号分块展示社区、游戏和云端结果，便于快速查看每个账号状态

### 失效账号定位

- `/ntelist` 会保留并展示已绑定账号的类型、序号、手机号尾号、`uid` 或 `cloudUid`
- 手动签到和自动签到失败时，结果中会先显示账号摘要，再显示失败原因
- 如果 `refreshToken` 或云异环 token 失效，可以根据账号序号和手机号尾号重新使用 `/ntepw`、`/nteph` 或 `/nteyun` 登录更新对应账号
- 角色签到结果会优先显示角色名；如果接口没有返回角色名，则显示角色 ID

### 定时签到

在插件配置中设置：

- `auto_sign_enabled`：自动签到开关
- `auto_sign_hour`：自动签到时间（小时，0-23）
- `auto_sign_minute`：自动签到时间（分钟，0-59）
- `auto_sign_delay`：每个用户签到前随机延迟秒数
- `max_users`：最大聊天用户数（0 为不限制）

说明：

- `max_users` 限制的是“可绑定的聊天用户数量”，不是单个用户可绑定的账号数量
- 单个聊天用户可以绑定多个异环账号

## 安装

### 方式一：从 Release 下载

1. 前往 Releases 页面
2. 下载最新的 `astrbot_plugin_nteV1.1.0.zip`
3. 在 AstrBot 插件页面上传该 zip 安装

### 方式二：使用 Git

```bash
cd /path/to/astrbot/plugins
git clone https://github.com/Candy-QAQ/astrbot_plugin_nte.git
```

## 依赖

插件依赖已在 `requirements.txt` 中列出，AstrBot 会自动安装。
